# 10. Memory Branch

The memory branch is where the CRT analogy becomes weakest and where the
encyclopedia must be most careful.

## Perception Is Not Memory

Perception:

```text
incoming signal -> present experience
```

Memory:

```text
experience + attention + context + emotion + association + consolidation
-> later reconstruction
```

A memory is not a video file stored in one location. It is distributed,
reconstructive, and influenced by later context.

## Useful But Safer Memory-Adjacent Concepts

| Concept | Status | Description |
| --- | --- | --- |
| Memory cue | Established | A photo, smell, sound, place, or phrase triggers recall. |
| Spaced rehearsal | Established | Repeated review strengthens retention. |
| Multisensory cueing | Research concept | Combining sensory cues can support recall. |
| Dream rehearsal notebook | Prototype concept | Images and narration are used to support voluntary recall. |
| Context restoration | Research concept | Recreating context can improve recall. |

## Frontier Concepts

| Concept | Why It Is Frontier |
| --- | --- |
| Direct visual memory writing | Not established, but useful for asking what memory representation would even mean. |
| Remote memory implantation | Far-edge concept that forces questions about carrier, target, transducer, and consent. |
| False-memory engineering | A misuse scenario worth naming because it clarifies the difference between support and manipulation. |
| Arbitrary dream insertion | Fiction-forward, but decomposable into cueing, imagery, sleep, and recall questions. |

## Creative Workaround: Cue, Don't Write

The ethical and practical workaround is to support voluntary memory formation:

```text
experience
-> image or narration
-> repeated review
-> emotional/context tags
-> user-controlled recall aid
```

This belongs closer to education, journaling, therapy support, or assistive
technology than neural writing.

## Expansion Rules

- Describe memory writing as a hypothesis space, not a finished tool.
- Keep cognitive cueing separate from neural stimulation.
- Treat memory as reconstruction, not playback.
- Use speculative labels as coordinates for exploration.
