# 11. Safety And Ethics

This encyclopedia includes medical and neurotechnology topics, so every
speculative idea needs boundaries.

Boundaries are not meant to make the encyclopedia timid. They make speculation
usable. A bold idea is easier to develop when the reader can see which parts are
known, which parts are imagined, and which parts would need evidence.

## Core Principles

| Principle | Meaning |
| --- | --- |
| Consent | No stimulation, recording, cueing, or cognitive influence without voluntary permission. |
| Reversibility | Prefer systems that can be turned off or removed safely. |
| Medical oversight | Eye, retina, nerve, and brain interventions require professional review. |
| Evidence labels | Established science, research, prototypes, and speculation must be separated. |
| No procedural harm | The encyclopedia should not become a guide for unsafe human experimentation. |
| User agency | The person using an interface must remain in control. |
| Privacy and data minimization | Camera, face, voice, location, neural, and memory data should be collected only when necessary, retained briefly, and deletable by the user. |
| Calibrated uncertainty | The system must expose uncertainty and failure modes instead of converting guesses into authoritative cues. |

## Forbidden Direction For This Project

- Instructions for applying electrical current to eyes or brain.
- DIY implant guidance.
- Stimulation parameter recipes.
- Claims of remote mind control or memory insertion.
- Coercive or deceptive cognitive influence.
- Unsafe laser, RF, magnetic, or ultrasound procedures.
- Silent collection, retention, or repurposing of biometric, neural, or memory data.
- Closed feedback loops that treat their own internal output as proof of success.

## Allowed Direction

- Concept maps.
- Literature summaries.
- Safety-focused comparisons.
- Fiction clearly labeled as fiction.
- High-level engineering tradeoffs.
- Wild hypotheses written as hypotheses.
- Far-future architectures with explicit missing pieces.
- Harmless toy models, metaphors, and diagrams.
- "What would need to be true?" analysis.
- Assistive technology ideas that preserve consent and control.
- Diagrams explaining known display and visual-system science.
- External evaluation plans that can weaken, reject, or revise the proposed model.

## Speculation Checklist

Before adding a speculative page, answer:

- What is the target?
- What is the carrier?
- What is the transducer?
- How is spatial addressing supposed to work?
- What evidence exists?
- What evidence is missing?
- What could go wrong?
- What ethical constraint is most important?
- Why is this not being presented as a current capability?
