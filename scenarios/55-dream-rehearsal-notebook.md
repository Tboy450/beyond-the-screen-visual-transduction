# 55. Dream Rehearsal Notebook

- Status: Prototype concept
- Interface point: Voluntary memory cueing
- Carrier: Ordinary images, narration, text, sound, and repetition
- Transducer: Normal senses and attention
- Encoding style: Multisensory recall prompts
- Addressing method: Personal association and review timing
- Expected percept: Stronger or more vivid voluntary recall
- Related modules: [Memory Branch](../modules/10-memory-branch.md), [Creative Engineering](../modules/13-creative-engineering.md)

## Summary

The dream rehearsal notebook is a grounded version of the memory branch. It does
not try to write memories directly. It explores how visual imagery and recall
can be shaped through ordinary cues: images, narration, context, emotion,
repetition, and sleep-adjacent review.

## Chain Map

```text
chosen event or imagined scene
-> image cue
-> narration cue
-> emotional/context tag
-> spaced review
-> later recall
```

## Why It Belongs Here

It is a memory-side analogue of screenless display. The "display" is not a
phosphor screen or neural implant. The display is a controlled set of cues that
the user voluntarily uses to reconstruct an internal scene.

## Expansion Ideas

- Memory lantern cards: each memory gets image, sound, location, and narrative
  anchors.
- Recall constellations: memories are grouped by shared symbols or spatial
  positions.
- Dream prompt decks: pre-sleep review cards that seed imagery without claiming
  control.
- Scene rehearsal: repeated visual summaries used for study, therapy support,
  or creative work.
- Accuracy journal: separate vividness from factual confidence.

## Research Questions

- Which cue combinations improve recall vividness?
- Which cues improve accuracy rather than only confidence?
- How does sleep timing affect later recall?
- Can generated imagery help memory, or does it increase distortion?
- How should a system preserve the difference between real memory, imagined
  scene, and edited reconstruction?
