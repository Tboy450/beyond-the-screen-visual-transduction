# 54. Associative Reconstruction

- Status: Research concept
- Interface point: Recall and imagination
- Carrier: Ordinary sensory cues, language, context, or symbols
- Transducer: Normal perception and attention
- Encoding style: Partial cues that reconstruct larger memories
- Addressing method: Association, context, salience, and repetition
- Expected percept: Recalled or imagined scene fragments
- Related modules: [Memory Branch](../modules/10-memory-branch.md), [Perceptual Rendering](../modules/09-perceptual-rendering.md)

## Summary

Associative reconstruction treats memory as a pattern rebuilt from fragments.
A cue does not need to contain the whole memory. It may only need to activate
the right associations.

## Chain Map

```text
cue
-> association
-> imagery and context
-> reconstructed memory
-> confidence and interpretation
```

## Cue Types

| Cue | Possible Effect |
| --- | --- |
| Image | Restores visual context. |
| Sound | Recalls place, event, mood, or timing. |
| Smell | Can strongly cue autobiographical memory. |
| Location | Rebuilds spatial context. |
| Phrase | Restores narrative or meaning. |
| Object | Anchors a specific event. |
| Emotion tag | Shapes salience and vividness. |

## Expansion Ideas

- Memory lantern cards.
- Recall constellations.
- Semantic diaries.
- Study systems that separate vividness from accuracy.
- Visual imagination maps.

## Research Questions

- Which cues restore the most accurate detail?
- Which cues increase confidence without accuracy?
- How do repeated cues alter the memory?
- Can a system show the difference between remembered, inferred, and imagined
  detail?
