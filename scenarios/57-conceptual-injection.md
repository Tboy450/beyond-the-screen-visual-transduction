# 57. Conceptual Injection

- Status: Frontier
- Interface point: Perception, cognition, and memory
- Carrier: Undefined in the wild version; ordinary cues in grounded versions
- Transducer: Perception, language, attention, or hypothetical future interface
- Encoding style: Meaning, image, belief, association, or memory cue
- Addressing method: Unknown for direct forms; context and attention for grounded forms
- Expected percept: Shifted interpretation, imagined content, or recalled association
- Related modules: [Memory Branch](../modules/10-memory-branch.md), [Creative Engineering](../modules/13-creative-engineering.md)

## Summary

Conceptual injection is the far-edge version of the project: can an idea, image,
or memory-like structure be introduced into experience without a normal screen?

The useful way to explore it is to split it into versions.

## Versions

| Version | Description |
| --- | --- |
| Ordinary cueing | Words, images, sounds, or places influence what someone imagines or remembers. |
| Semantic overlay | A device adds labels and interpretation to perception. |
| Training language | A learned cue system makes artificial symbols feel immediate. |
| Prosthetic percept | A retinal or cortical interface evokes artificial visual events. |
| Direct concept interface | A far-edge idea where meaning itself is delivered through a future interface. |

## Chain Map

```text
concept
-> cue or code
-> perception/attention
-> imagery or interpretation
-> memory or action
```

## Research Questions

- When does a cue become perception-like?
- How does language reshape visual attention?
- Can learned artificial symbols become automatic?
- What separates suggestion, imagination, memory, and perception?
- What would a non-metaphorical carrier for concept-level information require?
