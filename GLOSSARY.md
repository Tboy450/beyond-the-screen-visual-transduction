# Glossary

Short definitions for the encyclopedia. These are intentionally practical
rather than exhaustive. Select a term to read its related chapter or entry.

[Book home](README.md) · [Contents](CONTENTS.md)

| Term | Meaning |
| --- | --- |
| [Accommodation](modules/05-eye-optics.md) | The eye lens changing shape to focus at different distances. |
| [Active sensorimotor loop](modules/09-perceptual-rendering.md) | A perception-action cycle where movement helps structure what the user senses and learns. |
| [Addressing](modules/04-transducers.md) | Selecting where a signal goes, such as a pixel, retinal location, or cortical region. |
| [Air Loom](modules/16-air-loom-schizophrenia-and-influence-machines.md) | James Tilly Matthews's claimed hidden machine for remote influence, recorded by John Haslam in 1810. |
| [Amacrine cell](modules/06-retina.md) | Retinal interneuron involved in timing, motion, and local signal shaping. |
| [Analog signal](modules/02-signal-encoding.md) | A signal represented by a continuously variable physical quantity, such as voltage. |
| [Backlight](modules/01-display-physics.md) | Light source behind an LCD panel. |
| [Carrier](modules/03-carriers.md) | The physical medium or phenomenon carrying information. |
| [Cathode](modules/00-display-transduction-foundations.md) | Electron-emitting source in a CRT. |
| [Cathode-ray tube](modules/00-display-transduction-foundations.md) | Vacuum tube display that scans an electron beam onto phosphor. |
| [Cone](modules/06-retina.md) | Retinal photoreceptor important for color and high-acuity vision. |
| [Cortical prosthesis](modules/08-neural-interfaces.md) | Device intended to stimulate visual cortex to create useful percepts. |
| [Cue grammar](modules/09-perceptual-rendering.md) | A consistent rule set for turning features, events, confidence, and urgency into learnable outputs. |
| [Deflection](modules/00-display-transduction-foundations.md) | Steering a beam using electric or magnetic fields. |
| [Electrode array](modules/08-neural-interfaces.md) | Multiple electrical contacts used to stimulate or record tissue. |
| [Event camera](scenarios/50-event-based-vision-stream.md) | In a dynamic vision sensor, pixels report local brightness changes asynchronously; object meaning requires further processing. |
| [Feature code](modules/02-signal-encoding.md) | Representation using edges, motion, contrast, color, depth, or shape instead of pixels. |
| [Fovea](modules/05-eye-optics.md) | Central high-acuity region of the retina. |
| [Foveated rendering](modules/05-eye-optics.md) | Allocating high detail near gaze or attention and lower detail elsewhere. |
| [Frontier concept](sources/evidence-guide.md) | Far-future or not-yet-demonstrated idea preserved for hypothesis building and conceptual mapping. |
| [Ganglion cell](modules/06-retina.md) | Retinal output neuron whose axons form the optic nerve. |
| [Influencing machine](modules/16-air-loom-schizophrenia-and-influence-machines.md) | A psychiatric and historical term for a claimed machine experienced as controlling thoughts, sensations, feelings, movements, or speech. |
| [LGN](modules/07-visual-pathway.md) | Lateral geniculate nucleus, a thalamic relay in the visual pathway. |
| [MicroLED](modules/01-display-physics.md) | Display made from microscopic self-emitting LEDs. |
| [Object memory](modules/09-perceptual-rendering.md) | Interface memory that keeps track of important static objects after an event stream stops changing. |
| [OLED](modules/01-display-physics.md) | Organic light-emitting diode display, where pixels emit their own light. |
| [Optic nerve](modules/07-visual-pathway.md) | Bundle of ganglion-cell axons carrying visual information to the brain. |
| [Optogenetics](modules/08-neural-interfaces.md) | Technique that makes cells responsive to light through light-sensitive proteins. |
| [Passivity experience](modules/16-air-loom-schizophrenia-and-influence-machines.md) | Experience in which thoughts, feelings, impulses, or actions seem to be generated or controlled from outside the self. |
| [Perception-as-medium](modules/09-perceptual-rendering.md) | Design stance where the trained human perceptual loop completes the representation instead of a device carrying a full image. |
| [Perceptual codec](modules/09-perceptual-rendering.md) | Encoder that preserves task-useful cues rather than full photorealistic imagery. |
| [Phosphene](modules/08-neural-interfaces.md) | Perceived light sensation not caused by ordinary light entering the eye. |
| [Phosphor](modules/00-display-transduction-foundations.md) | Material that emits visible light after excitation. |
| [Photoreceptor](modules/06-retina.md) | Retinal cell that converts light into biological signals. |
| [Phototransduction](modules/06-retina.md) | Biological conversion of light into cellular/electrical activity in photoreceptors. |
| [Pixel](modules/01-display-physics.md) | Smallest addressable picture element in a display. |
| [Population code](modules/02-signal-encoding.md) | Information represented by activity across many neurons. |
| [Raster scan](modules/00-display-transduction-foundations.md) | Line-by-line scanning pattern used by CRTs and video systems. |
| [Receptive field](modules/07-visual-pathway.md) | Region of sensory space that affects a neuron or cell. |
| [Retina](modules/06-retina.md) | Neural tissue at the back of the eye that detects and preprocesses light. |
| [Retinal prosthesis](modules/06-retina.md) | Device that stimulates retinal tissue to produce useful visual percepts. |
| [Retinotopy](modules/07-visual-pathway.md) | Spatial mapping where neighboring visual-field points map to neighboring neural tissue. |
| [Rod](modules/06-retina.md) | Highly light-sensitive photoreceptor important for low-light vision. |
| [Semantic cue](modules/02-signal-encoding.md) | Meaning-level information, such as "door ahead" or "person right." |
| [Sensory substitution](modules/09-perceptual-rendering.md) | Translating information from one sense into another, such as vision into touch. |
| [Spike train](modules/02-signal-encoding.md) | Sequence of neural action potentials over time. |
| [TMS](modules/08-neural-interfaces.md) | Transcranial magnetic stimulation, a noninvasive way to induce neural activity using magnetic fields. |
| [Transducer](modules/04-transducers.md) | A device or biological mechanism that converts a physical input into another form of energy or signal. |
| [Transparent tool](modules/09-perceptual-rendering.md) | A tool that becomes fluent enough that the user attends through it to the world rather than mainly attending to the tool itself. |
| [V1](modules/07-visual-pathway.md) | Primary visual cortex. |
| [Visual prosthesis](modules/08-neural-interfaces.md) | Device intended to restore or substitute some visual function. |
| [Waveguide](modules/05-eye-optics.md) | Optical structure that routes light, often used in near-eye displays. |
