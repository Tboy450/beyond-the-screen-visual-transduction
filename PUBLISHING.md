## Recommended Order

### Easiest First

1. Hacker News regular submission.
   Lowest technical work: title, URL, and one context comment. Use a regular
   submission unless an interactive demo is added.

2. PRLog free press release.
   Low technical work: create/login to an account, paste the press release,
   choose category/tags, and submit.

3. Hackaday.io project page.
   Low technical work: create/login to an account, create a project, paste the
   project description, add repository link, and add a few project logs.

4. Product Hunt draft launch.
   Moderate work: create/login to an account, paste name/tagline/description,
   add images, and schedule or publish a launch. Stronger after a public docs
   site exists.

5. GitBook docs site.
   Moderate work: create/login to GitBook, import or sync the repository, set
   the site public, and publish.

6. Read the Docs site.
   Moderate technical work: create/login to Read the Docs, connect GitHub or
   install the GitHub App, import the repository, and add a MkDocs or Sphinx
   build configuration if needed.

7. Zenodo DOI archive.
   Moderate account/setup work: create/login to Zenodo, connect GitHub, enable
   the repository, choose a license, and publish a GitHub release so Zenodo can
   archive it.

8. Figshare research output.
   Moderate account/setup work: create/login to Figshare, upload files, add
   metadata, choose a license, reserve or publish a DOI, and review the record.

9. OSF Preprints.
   More preparation: create/login to OSF, upload a paper-style file, add
   metadata, choose discipline tags, and submit.

10. arXiv.
    Highest scholarly preparation: author account, formal manuscript,
    complete references, category selection, PDF/source checks, and possible
    endorsement depending on category/account status.

11. EIN Presswire.
    Paid PR path: account, press release, category/geography targeting,
    checkout, editorial review, and distribution.

12. PR Newswire.
    Paid broad PR path: account or sales workflow, press release, multimedia
    assets, targeting, checkout, editorial review, and distribution.

### Best Practical Order

1. Submit a regular Hacker News link and a PRLog free release.
2. Create a Hackaday.io project page.
3. Publish a GitBook site, then use that cleaner public URL for Product Hunt.
4. Add Zenodo or Figshare once the title, creator metadata, and license are
   final.
5. Use OSF/arXiv after the repository becomes a focused paper.
6. Use EIN Presswire or PR Newswire only when there is a clear launch, DOI,
   site URL, or research milestone.
